# Asra

Android WebView uygulaması ve site dosyaları.

## Dosyalar

- `asra.apk` — kurulabilir uygulama (1.5.3)
- `android/` — Kotlin kaynak kodu
- `site/index.html` — arayüz
- `site/auth.php` — API

## Kurulum

1. `asra.apk` dosyasını cihaza kur.
2. `site/index.html` ve `site/auth.php` dosyalarını sunucuya yükle.
